# FunDrivenDev · Instruções de desenvolvimento

Este é o repositório central dos jogos do projeto Jogos de Alexander.

- Leia o README raiz e as instruções da pasta do jogo antes de editar.
- Salve cada jogo em `jogos/<slug>/`, com `index.html` e README próprios.
- Atualize `README.md` e `index.html` da raiz ao adicionar ou remover jogos.
- Preserve os jogos existentes. Não exclua cópias em outros repositórios sem instrução.
- Prefira soluções simples e independentes; adote engines, backends ou dependências quando necessários e justificados.
- Execute `python3 scripts/check.py` antes de concluir mudanças.
- Verifique a jogabilidade quando houver navegador disponível. Informe o que não foi testado.
- Não afirme que CI, acessibilidade, compatibilidade ou publicação foram aprovados sem evidências.
- Não divulgue URLs de jogo como publicadas antes de verificar a implantação.
- Não introduza licenças, assets sem permissão, cobranças ou serviços pagos sem decisão do autor.
- Nunca adicione credenciais ao repositório.
